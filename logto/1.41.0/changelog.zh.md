## 亮点

- **应用程序级访问控制**：按用户、用户角色、组织或组织角色限制应用程序访问。
- **密码过期策略**：强制每个租户进行密码轮换，并让管理员手动使用户的密码过期。
- **帐户中心升级**：现在可以使用会话、个人资料、头像上传和独立的密钥控制。

## 新功能和增强功能

### 应用级访问控制

管理员现在可以限制谁可以访问应用程序。访问规则支持：

- 用户 ID
- 用户角色
- 组织
- 组织角色

当用户与配置的规则不匹配时，Logto 将通过拒绝访问页面阻止登录或应用程序访问流。

文档：<https://docs.logto.io/integrate-logto/app-level-access-control>

### 密码过期策略

控制台现在支持安全 -> 密码策略下的每租户密码过期策略。

管理员可以：

- 启用密码过期。
- 配置密码的有效天数。
- 从用户详细信息页面手动使特定用户的密码过期。

当密码过期时，用户必须通过配置的恢复方法重置密码，然后才能继续密码登录。 SSO 和密钥登录不受影响。

没有记录密码更改时间的旧用户将被锚定到策略启用的时间，因此他们会收到完整的有效期，而不是立即过期。

### 账户中心

账户中心现包括：

- 用于查看活动会话和连接的第三方应用程序的会话管理。
- 个人资料管理和头像上传。
- 收集个人资料注册期间支持头像上传。
- 独立于 MFA 的独立密钥控制。
- 用户控制密钥登录提示首选项。

帐户中心个人资料页面、注册时的自定义个人资料字段和头像上传端点作为开箱即用的个人资料体验的一部分提供。

### 用户名政策

操作员可以从控制台 -> 登录体验 -> 注册和登录 -> 高级选项配置租户级用户名规则。

该策略涵盖区分大小写、长度限制和允许的字符类型。它强制执行于最终用户在注册、配置文件履行、帐户中心和帐户 API 中写入的用户名。

切换到不区分大小写的用户名受到保护：Logto 会检测仅大小写不同的现有用户名，并阻止更改，直到解决冲突。

当取消设置“profile.preferredUsername”时，OIDC“preferred_username”声明现在会回退到用户的“username”。

### 验证码和消息发送控件

管理员可以在控制台安全设置中配置验证码过期时间和最大重试尝试次数。

Logto 还跨电子邮件/短信验证和邀请发送路径添加了系统级每个收件人的发送速率限制，包括体验、MFA、帐户 API、管理 API、组织邀请和旧版交互 API。

当发送受到限制时，Logto 会发出“Message.RateLimited”Webhook 事件，现在可以在控制台 Webhook 设置中选择。禁用注册时，将禁止向未知收件人发送验证码，以降低帐户枚举风险。

### JWT 定制器组织上下文

对于组织 API 资源令牌，访问令牌 JWT 定制器现在接收带有目标组织的“id”、“name”、“description”和“customData”的“context.organization”。

这允许脚本附加每个组织的声明，而无需将每个组织映射嵌入到每个令牌中。

### API 改进

`POST /api/applications/:applicationId/roles` 现在是幂等的。已附加到应用程序的角色 ID 将被忽略，而不是返回“422 application.role_exists”。

端点现在返回带有“{ roleIds，addedRoleIds }”的“201”，与用户角色分配 API 形状匹配。

现在，具有初始作用域的组织角色创建是事务性的，因此无效的作用域 ID 不再留下部分创建的角色。

## 错误修复和稳定性

### 安全和协议强化



- SAML IdP 自动提交表单现在转义 HTML 属性值并拒绝非 HTTP(S) 操作 URL。
- `samlify` 升级到 `^2.13.0`，改进了生成的 SAML 断言中的 XML 转义。
- TOTP MFA 验证现在拒绝来自相同或较旧时间步计数器的重播代码。
- 包含空字节的 OIDC 请求主体现在返回“400 invalid_request”，并且审核日志有效负载在插入之前去除空字节。
- 电子邮件子地址阻止列表检查不再根据用户控制的输入构建正则表达式。
- Logto Tunnel 可防止静态文件请求在配置的体验路径之外读取。

### 体验与账户中心

- 租户主题、平台和品牌颜色在水合之前应用，以减少登录体验和帐户中心中的主题闪现。
- 托管登录体验自定义 CSS 现在内联到服务器渲染的 HTML 中，以防止内置样式闪烁。
- 账户中心升压验证仅限于用户权限验证记录。
- 当用户没有旧的安全验证方法时，可以在帐户中心链接社交身份，无需密码、电子邮件或电话验证。
- 控制台用户名编辑现在重定向到帐户中心，以便完成所需的验证流程。

### 兼容性和存储

- 旧版 Safari 和 iOS 15 不再因不支持的正则表达式后向语法而在启动时崩溃。
- OIDC 企业连接器可以从拒绝仅 JSON 响应协商的提供商获取发现配置。
- 自定义 UI 资产 Azure Blob 传输失败现在映射到可重试的存储下载错误，并且上传超时处理得到了改进。

## 连接器

- **新增 - SMTP2GO 电子邮件连接器**：通过 SMTP2GO 发送 API 发送事务验证电子邮件。
- **QQ 连接器**：支持通过存储的重定向 URI 进行社交身份验证。
- **SAML 连接器**：升级 `samlify` 并适应其更严格的返回类型。
- **连接器套件**：导出共享 SMTP 邮箱解析和格式化实用程序，现在也由 MailJunky 使用。

## 自托管和 OSS 注释

- **`CASE_SENSITIVE_USERNAME` 弃用**：环境变量仍可作为运行时覆盖，但现在应通过用户名策略为每个租户配置用户名区分大小写。它已被弃用并计划在下一个主要版本中删除。
