## @hyperdx/app@2.40.0

### 次版本变更

- 8a9fcd2f：功能：支持在 PromQL 图表中使用宏。

- 08d9a908：功能：在同一张图表中绘制多个 PromQL 表达式。

- d9e2c58b：为每个数据源添加自动时间粒度下限。指标数据源现在可以设置“最小自动时间粒度”（团队设置 → 数据源 → 你的指标数据源），使自动推断的时间桶不会小于该值。当底层指标按固定间隔上报时（例如每 60s 抓取一次），这一设置很有用：否则，较短的所选日期范围可能自动推断出小于上报间隔的时间桶，渲染出稀疏或阶梯状的序列（实际样本桶与空桶交替出现）。这与 Grafana 针对每个数据源的“最小间隔”设置相对应。未设置时（默认情况）保留现有的无下限行为；磁贴上明确选择的非自动时间粒度始终不受影响。

- d76cb7ed：在事件侧边面板中新增“Trace 日志”标签页，在与瀑布图相同的时间窗口内，以按时间排序的扁平表格列出该 Trace 的日志。任何带有 Trace ID 且能够确定日志数据源的行都会显示此标签页：Span 通过 Trace 数据源的关联日志数据源确定，日志则使用自身的数据源。此前，查看 Trace 日志的唯一途径是在瀑布图中寻找穿插其中的绿色行；日志较多的 Trace 会使这些行难以找到。

  该标签页列出未经筛选的 Trace 日志；“在搜索中打开”会将相同的查询——相同数据源、相同 Trace、相同时间窗口——交给搜索页面，以便进一步缩小范围。选中日志会在面板中打开它：从 Span 打开时通过面包屑导航跳转，从另一条日志打开时则切换行。排序为升序，在同一 Trace 内对应执行顺序。

- f800b090：新增“偏好设置 → 搜索结果 → 行点击”设置。保持 `Open side
panel`（默认值）即可沿用现有行为，设置为 `Expand inline` 则会在点击行时就地展开该行——浏览日志时，很难准确点击展开箭头仅 16px 的命中区域。启用行内展开后，侧边面板的入口移至行上的悬停按钮；从已展开的行仍只需一次点击即可打开面板，面板打开期间也会继续接收行点击。

### 补丁变更

- 416c92a0：修复：大数值的图表坐标轴刻度不再丢弃小数。

  此前，达到或超过 1k 的坐标轴刻度始终会取整，无论配置了何种数字格式，因此相近的值（例如 950 和 1080）可能都显示为 `1k`。现在，Web 应用和 CLI 终端图表中的刻度都会使用坐标轴宽度所允许的精度。同时修复了 Y 轴范围较紧时，两个刻度可能显示相同舍入标签的问题。

- 1e355ac4：修复：发现 Map 键时不再扫描整张表。

  `getMapKeys` 此前仅在调用方同时传入日期范围和时间戳表达式时才应用时间谓词；否则，原始 `sampledKeys` 扫描没有 `WHERE` 条件，会访问表中的每个 Part。现在，缺少日期范围时默认使用最近 24 小时；没有可用于筛选的时间戳表达式时，则完全跳过原始扫描。图表、告警和仪表盘筛选器编辑器会传入它们已有的数据源和日期范围，使 Map 键在这些位置仍能自动补全。

- ec25b813：修复：图表编辑器处于 PromQL 模式时，只提供 PromQL 数据源。

- c47b9b9e：修复：通过标签页、排序和标签筛选重构仪表盘列表。

  带标签的仪表盘不再在其每个标签下重复出现；网格中每个仪表盘只列出一次。标签现在通过带计数徽标、固定宽度的“标签”按钮进行筛选（仪表盘必须包含所有选中的标签）。收藏项从固定的一行卡片移至“全部 / 收藏 / 我的仪表盘”标签栏；排序控件提供最近更新（默认）、名称和最近创建三种方式。“导入”和“新建仪表盘”移至页面标题区。

- 5e3031da：修复：显示数值、条形图和饼图磁贴正在刷新。

  仪表盘刷新期间，这些磁贴此前会在屏幕上保留旧结果，却没有任何新数据正在加载的提示，使过期数值看起来仍是最新值。现在，重新获取数据时它们会显示脉动效果，与折线图和堆叠条形时间图已有的行为一致。

- 517ffd90：修复：仪表盘刷新期间保留屏幕上的热力图磁贴。

  刷新期间，热力图磁贴此前会将图表替换为“加载中...”消息，直到新数据到达。现在，它们会保留当前热力图，并在重新获取数据时显示脉动效果，与其他仪表盘磁贴一致。

- 6452baaf：修复：将 Live Tail 时间选择器的预设范围扩展至 6h，并明确开关标签。

  在 Live Tail 模式下启用 3h 和 6h 预设（此前选择器中的上限为 1h，尽管通过 URL 已可使用更长范围）。超过 6h 的范围仍被禁用，因为每次刷新（默认每 10s）都会重新查询整个时间窗口，扫描 12–24h 的数据开销过大。将开关从“相对时间”重命名为“Live Tail 范围”，明确其控制的是可用的预设间隔，而非是否启用 Live Tail。为禁用的预设（12h 及以上）添加“不适用于 Live Tail”工具提示。

- 0c93eab0：修复：从搜索侧栏添加的 Map 属性列使用键名作为列标签。

  从筛选器侧栏或行侧边面板将 `ResourceAttributes['service.name']` 这样的 Map 属性添加为列时，现在会在 SELECT 中写入 `ResourceAttributes['service.name'] AS "service.name"`，因此结果列显示为 `service.name`，而非 `arrayElement(ResourceAttributes, 'service.name')`。别名在 SELECT 中可见且可编辑，手动输入的查询不会被修改。如果键名与表列同名，或已被 SELECT 中的其他名称使用，则添加时不附加别名。

- 793fe19e：功能：在 Markdown 磁贴中替换仪表盘变量。

- ec4f5087：修复：允许 Gauge 和 Sum 指标图表按物化列和别名列分组。

  此前，在 Gauge 或 Sum 指标图表中按 MATERIALIZED 或 ALIAS 列分组或选择这些列，会因中间查询未传递这些列而失败，报错 `Unknown expression identifier`。

- 4fa3c376：修复展开和折叠行后搜索结果变为空白的问题。一行及其行内展开内容是两个共享同一虚拟索引的 `tr`，两者都会被虚拟化器测量，因此展开行会接管该索引的 ResizeObserver 注册，并在折叠后将自身高度继续缓存于该索引。每次展开或折叠都会使渲染窗口进一步缩小，直到滚动时只显示少数几行，其下方均为空白。现在，行及其展开内容包裹在一个 `tbody` 中，作为一个整体进行测量。

- bd40e3cb：修复（app）：修复在 Distributed 表上选择事件差值失败的问题。

- a8a72c11：修复：PromQL 数值磁贴支持即时查询和归约操作。

- 8cfb2672：功能：PromQL 范围查询数值磁贴支持背景迷你趋势图。

- 4570d5ee：功能：PromQL 数据源支持饼图和条形图磁贴。

- 78ed5921：功能：PromQL 数据源支持表格磁贴。

- 23423c13：修复：“显示分布”仅在样本表明某个值很少见时才将其标为“<1%”，而非在没有匹配行时如此标记；字段的筛选条件只允许该值时则显示 100%。

- 5bdb68db：功能：新增在行详情面板中显示 MATERIALIZED 和 ALIAS 列的选项。

  ClickHouse 的 `SELECT *` 不包含 MATERIALIZED 和 ALIAS 列，因此行详情面板此前从未显示这些列。属性视图选项菜单新增“显示物化列和别名列”选项，默认关闭；启用后会向行查询添加 `asterisk_include_materialized_columns` 和 `asterisk_include_alias_columns`。对于配置了已知列列表的数据源，该选项不起作用；如果数据源的查询设置已经为其中任一设置指定了值，则以该值为准。启用此选项时，如果行加载失败（例如连接用户的设置为 `readonly = 1`，或某个 ALIAS 列无法求值），错误状态会提供关闭此选项的操作。

- 9647ad3d：修复：行侧边面板查找行时应用数据源的查询设置。

- 4c4792f5：修复：移除搜索栏的 WHERE 标签和 `/` 按键提示浮层。

  `WHERE` 标签重复了 SQL 占位文字，而 `/` 提示会遮挡较长的查询。`/` 和 `s` 仍可使输入框获得焦点；仅移除了浮层。

- 67673498：修复启用 Live Tail 时搜索页面占用的浏览器内存持续增加的问题。此前，每次刷新都会为 SELECT 和 ORDER BY 编辑器添加 CSS 规则，但这些规则从未被移除，因此长期保持打开的标签页可能多占用数 GB 内存。

- c2c26093：功能：悬停时显示搜索结果行的选择复选框。

  多选复选框现在会在行被悬停或复选框获得键盘焦点时淡入，而非始终出现在每一行上；尺寸也略微缩小，使其所在列占用更少的横向空间。选中任意行后会显示所有复选框，方便准确执行 Shift 点击范围选择；触控设备（没有悬停）上则始终显示。单元格在所有状态下都保持相同宽度，因此悬停不会引起布局重排。

- 19182e7e：修复：仅在独立的 SETTINGS 关键字处拆分查询。

  `extractSettingsClauseFromEnd` 此前会在查询中首次出现“settings”的任意位置截断查询，包括字符串或标识符内部。使用 `app.settings.reloads` 等指标的多序列指标图表会生成包含未终止字符串的 SQL，而针对 `AppSettings` 等列的 SQL 筛选条件会被改写为引用 `App`。现在，该关键字必须位于引号之外并独立出现。

- 1edc042a：修复：仪表盘刷新期间保留屏幕上的表格磁贴行。

  仪表盘刷新此前会清空表格磁贴，并显示“正在加载图表数据...”，直到新结果到达。现在，磁贴会保留当前行，并在重新获取数据时显示脉动效果，与其他仪表盘磁贴一致。

- 16c7a6c3：修复：使工具栏控件与发生换行的查询字段的首行保持对齐。

  SQL 或 Lucene 字段高度增加时，日期选择器、“运行”按钮以及附近的行操作控件会保持顶部对齐。Sessions 启用了 PageHeader 的块方向内边距，使较高的搜索栏仍有足够空间。

- fb2aebc9：修复：将视口初始缩放比例设为 1，使移动浏览器加载应用时不再缩小至 75%。

- e24acf73：修复：使 Y 轴刻度间距一致，并舍入为规整的数值。

  图表的 Y 轴此前可能渲染出间距不一致或带小数的刻度（例如 `0, 300, 1k`，而非 `0, 250, 500, 750, 1k`），甚至显示两个标签相同的刻度。现在，刻度会舍入为规整、间距一致且始终互不相同的数值。
