## 概览

本周期为 HyperDX 应用加入内置更新日志、智能 Rollup 查询路由、指数直方图和仪表盘交互增强，并聚合 API、common-utils 与 otel-collector 的同期变化。

## New Feature

- Help 菜单新增以 Markdown 展示的 “What’s new”。
- 过滤与自动补全可智能选择最佳 Rollup。
- 支持指数直方图指标、仪表盘拖拽网格、语义化组件样式与 Trace span links。

## Bugfix / Security

- 修复多选搜索框、Trace 详情和 MCP Codex CLI 安装示例等问题。
