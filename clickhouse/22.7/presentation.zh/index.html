新的 JOIN 算法

— "direct”算法：
  通过直接查找（也称嵌套循环）与键值表连接。
  适合左表较小、右表类似大型字典的情况。
  适用于 MATERIALIZED VIEW 查询。

— "parallel_hash”算法：
  右表较大时可提速。

— "full_sorting_merge”算法：
  适用于右表较大、
  无法放入内存且不支持查找的情况。

— "grace_hash”算法：
  预计在 22.8 中推出。

开发者：Vladimir Cherkasov、lgbo-ustc。

查询外附加筛选条件

SET additional_table_filters = {'t': $$ name != 'Petya' $$}; CREATE TEMPORARY TABLE t (name String); INSERT INTO t VALUES ('Vasya'), ('Petya'); SELECT * FROM t; ┌─name──┐ │ Vasya │ └───────┘
