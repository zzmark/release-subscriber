自解压可执行文件

安装 ClickHouse 最简单的方式：

curl https://clickhouse.com/ | sh

单一二进制软件包。安装最新版本，包含调试信息。

可运行于各种 Linux (x86_64, aarch64, powerpc64le),
macOS (x86_64, M1), FreeBSD 和 Windows (WSL2).

此前：2.1 GB。

现在：446 MB，首次运行时约需 5 秒解压。

开发者：Arthur Filatenkov、Yakov Olkhovskiy。

扩展日期与时间范围

数据类型 DateTime64 和 Date32 的支持范围：

此前：1925–2283.

现在：1900–2300.

采用前推格里高利历。

动机：存储客户的出生日期。

开发者：Roman Vasin。

分布式 INSERT SELECT FROM s3Cluster

SELECT * FROM s3('https://clickhouse-public-datasets.s3.amazonaws.com/ wikistat/partitioned/wikistat*.native.zst'); SELECT * FROM s3Cluster('default', 'https://clickhouse-public-datasets.s3.amazonaws.com/ wikistat/partitioned/wikistat*.native.zst'); INSERT INTO wikistat SELECT * FROM s3Cluster( 'https://clickhouse-public-datasets.s3.amazonaws.com/ wikistat/partitioned/wikistat*.native.zst');

如果目标表为 Replicated 或 Distributed
，INSERT 将在集群中分布式执行。

AggregateFunction 状态的兼容性

不同聚合函数可以具有兼容的状态。

兼容的状态 可以插入包含 AggregateFunction 类型列的表。

有助于使用物化视图和投影。

例如：avg(price) 和 avgIf(price, category = 'flowers')

例如：quantile(0.5)(timing) 和 quantiles(0.5, 0.9)(timing)
