非常量 LIKE 和 match

SELECT DISTINCT repo_name, title
FROM github_events
WHERE title ILIKE (
  repo_name LIKE '%ClickHouse%' ? '%fast%' : '%slow%')
AND repo_name IN ('ClickHouse/ClickHouse', 'elastic/elasticsearch')

现在可以把 LIKE 放进 LIKE 里面了，看来你会“喜欢”（like）它。

开发者：Robert Schulze。

INSERT INTO ZooKeeper

INSERT INTO system.zookeeper (name, path, value)
VALUES ...

在 ZooKeeper 中创建新的持久节点。

批量 INSERT 会在事务中创建多个节点。

请不要随意操作 ZooKeeper，也不要使用此功能。

开发者：Han Fei。

参数化可执行 UDF

SELECT my_function('hello')(x)

参数将代入命令模板：

./myprogram --xyz {param:String}
./myprogram --xyz 'hello'

注意：仅允许直接“exec”，不能使用 shell 解释器。
因为 shell 解释器对字符串字面量中转义序列的解释
与 SQL 不同。

开发者：Maksim Kita。

clickhouse-disks 工具

clickhouse-disks \
  --config-file ... \
  --disk ... \
  list|read|write|remove|link|copy path

用于检查和操作 ClickHouse VFS 的工具

可以操作对象存储（S3、HDFS、Azure、Web）上的文件

开发者：Artyom Yurkov。

性能改进

使用 ARM NEON 为 AArch64 带来大量优化！

(Apple M1, AWS Graviton...)

几乎涵盖所有底层向量指令、LZ4 和 ZSTD 优化，
以及 UTF-8 处理、字符串函数和排序等诸多方面……

现在，AArch64 已成为 ClickHouse 的一等公民！

开发者：Daniel Kutenin（Google）、Alexandra Pilipyuk。

性能改进

顺便一提……AArch64 构建现在可以正确提供堆栈跟踪。

（异常、system.stack_trace、查询性能分析器）

开发者：Maksim Kita。

性能改进

优化 COALESCE。

优化 multiIf 的单分支情况。

优化 L1/L2/Lp/Linf 距离和范数函数。

优化 数字比较。

使用 AVX-512 优化 hasAll。

优化 greatCircleAngle, greatCircleDistance, geoDistance。

开发者：Maksim Kita、Anton Popov、Alexander Gololobov。

性能再提升

优化 带 LIMIT 的 ORDER BY。

优化 ORDER BY 的单列情况。

优化向具有复合排序键的 MergeTree 执行 INSERT。

优化 dictGetChildren, dictGetDescendants。

优化具有大型 GROUP BY 的查询的清理阶段。

优化大量表的 后台 CPU 使用。

开发者：Maksim Kita、Nikita Taranov。
