集成 Arrow Flight 🧪

从 25.8起，ClickHouse 可以查询其他 Arrow Flight 数据源
，使用的是 arrowFlight 表函数。

ClickHouse 本身也可以作为 Arrow Flight 服务器 运行。

新增于 25.9：TLS 和认证。

-- without authentication: SELECT * FROM arrowFlight('host:port', 'dataset_name'); -- with authentication: SELECT * FROM arrowFlight( 'host:port', 'dataset_name', 'username', 'password');

开发者：Vitaly Baranov。

新的内存分析器

ClickHouse 已有 采样 和 水位线 内存分析器。

现在使用内存分配器（jemalloc）对内存分配和释放进行 一致采样 。

默认内置于 ClickHouse，可在运行时使用：

:) SET jemalloc_enable_profiler; :) SET jemalloc_collect_profile_samples_in_trace_log; -- after collecting some data :) SELECT arrayStringConcat(symbols, '\n') AS s, count() AS c, sum(size) AS size, round(size / c) AS avg_size FROM system.trace_log WHERE trace_type = 'JemallocSample' GROUP BY s ORDER BY abs(size) DESC LIMIT 20 FORMAT Vertical

开发者：Antonio Andelic。

性能改进

流式处理二级索引

在 25.8中：查询开始读取数据前，先读取并分析索引，使用大型索引时会引入明显延迟。

在 25.9中：在扫描数据的同时读取索引。查询启动更快，也可更早完成，例如达到 LIMIT 时。

向量索引

HNSW 算法，支持量化选项（bf16, i8, b1）。

支持不同的过滤模式：
后置过滤 （先执行近似近邻搜索，再应用其他过滤条件）
或 前置过滤 （先应用常规过滤条件，再对过滤后的结果执行近似近邻搜索）。

支持过滤倍数
（例如先找到 100 个最近候选，过滤后返回 10 个）。

不必要时避免读取数据列。

开发者：Shankar Iyer。
