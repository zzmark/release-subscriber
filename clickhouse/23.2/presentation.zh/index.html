开发者：ucasFL。

数据湖

ClickHouse 现已支持对 Apache Hudi、 Delta Lake、 Apache Iceberg
执行 SELECT 查询。

— ClickHouse 可以与各种系统集成！
— s3, hdfs, https, mysql, postgres, sqlite, mongodb, jdbc, odbc...
— 无需加载，即可查询数据！

优点：
— 这些格式与 MergeTree
  有些相似，允许增量插入数据，
  正在向 ClickHouse 数据格式靠近；

缺点：
— 一种修修补补的数据组织方案；
