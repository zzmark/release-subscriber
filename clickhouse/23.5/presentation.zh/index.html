从临时表执行 ATTACH ...

在暂存表内准备数据，
再以一个大批次挂载。

CREATE TEMPORARY TABLE src (x UInt64) ENGINE = MergeTree ORDER BY x; INSERT INTO src SELECT * FROM numbers(1000000); ... ALTER TABLE dst ATTACH PARTITION () FROM src;

也适用于 REPLACE PARTITION 。

开发者：Roman Vasin。

实验性功能达到生产可用状态

查询结果缓存

— 默认在用户之间安全隔离；
— 将查询规范化为 AST；
— 遵循查询设置，并考虑非确定性函数；
— 可控制每个条目及整体大小；
— 可启用主动写入或仅使用已有缓存的模式；
— 自 23.5 起可用于生产环境！

地理数据类型

— Point、Ring、Polygon 和 MultiPolygon 数据类型；
— 距离、面积、周长、并集、交集、凸包等函数；
— 笛卡尔坐标和球面坐标；
— 从 WKT 读取，输出为 SVG；
— 自 23.5 起可用于生产环境！

默认启用的功能

磁盘上的压缩标记和索引

— 自 22.9 起可用；
— 提高服务器启动后首次查询的速度；
— 23.5 中默认启用。

后台操作的内存使用

控制内存使用的新服务器设置：

merges_mutations_memory_usage_soft_limit 和
merges_mutations_memory_usage_to_ram_ratio = 0.5

如果后台操作已经消耗超过一半的
服务器内存，就不再启动合并和变更操作。

开发者：Dmitri Novik。

降低内存使用的新表设置：

merge_max_block_size_bytes 和 vertical_merge_algorithm_min_bytes_to_activate
— 合并具有大型行的表时节省内存；

开发者：Nikita Mikhaylov。
