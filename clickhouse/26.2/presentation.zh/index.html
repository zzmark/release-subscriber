性能改进

更多场景可使用主键索引

当表按列上的表达式排序时：

CREATE TABLE pageviews (user_id UInt64, ...) ORDER BY cityHash64(user_id)

在 25.1 中，此查询不会使用索引： SELECT * FROM pageviews WHERE user_id = 123456; 可以按以下方式使其使用索引： SELECT * FROM pageviews WHERE user_id = 123456 AND cityHash64(user_id) = cityHash64(123456);

在 26.2 中，两条查询都会使用索引！

开发者：Nihal Z. Miaji。

更多表达式可使用索引

当表按列上的表达式排序时：

CREATE TABLE pageviews ( user_id UInt64, region LowCardinality(Nullable(String)), lat Nullable(Float64), lon Nullable(Float64), INDEX idx_region (region) TYPE set(100), INDEX idx_lat (lat) TYPE minmax, INDEX idx_lon (lon) TYPE minmax, );

SELECT user_id FROM pageviews WHERE coalesce(region, 'n/a') = 'Amsterdam' AND ifNull(lat, 0) BETWEEN -10 AND 10

按数据库延迟加载表

CREATE DATABASE db_name ENGINE = Atomic SETTINGS lazy_load_tables = 1;

启用此设置后，服务器启动时不会加载表，
每张表会在首次使用时加载。

开发者：XiaoHuanLin。

按时间批处理“无限”插入流

向 ClickHouse 插入无限数据流：

curl -sS --globoff -H 'Accept: application/json' --no-buffer \ "https://stream.wikimedia.org/v2/stream/recentchange" | clickhouse-client --query " INSERT INTO wikipedia_edits FORMAT JSONAsObject" \ --min_insert_block_size_rows=0 --min_insert_block_size_bytes=0 \ --input_format_max_block_wait_ms 1000 --input_format_connection_handling 1

这样可以工作，但数据多久会刷新到表中？
— 取决于数据速率和 min_insert_block_size。

ClickHouse 26.2 引入新设置 input_format_max_block_wait_ms， — 可按时间而非块大小定义刷新间隔。

开发者：Mostafa Mohamed Salah。

SELECT id, name FROM vectors ORDER BY L2DistanceTransposed(vector, target, 10) LIMIT 10;

ClickHouse AI 政策

https://github.com/ClickHouse/ClickHouse/blob/master/AI_POLICY.md

ClickHouse 开发可以使用 AI。我们欢迎并拥抱 AI 的使用，也欢迎针对前沿 AI 模型，以及 AI 在软件工程中的新型应用方式开展研究和实验。

你无需披露自己使用 AI 的情况。你可以介绍它、分享经验并展示方法，但这不是强制要求。AI 是开发者的普通工具，就像 IDE、操作系统或键盘。我们不会因是否使用 AI 而评判你的工作，但建议在提交 Pull Request 前认真清理低质量内容，否则可能损害你的工程师声誉。
