RIPEMD160

这是一个不应再使用的旧密码学哈希函数。

:) SELECT hex(RIPEMD160('Hello, world!')) ┌─hex(RIPEMD160('Hello, world!'))──────────┐ 1. │ 58262D1FBDBE4530D8865D3518C6D6E41002610F │ └──────────────────────────────────────────┘

但比特币使用它。
而很多公司正在用 ClickHouse 处理区块链数据。

所以 ClickHouse 现在也有它了！

开发者：Dergousov Maxim。

MongoDB 查询改进

你知道 ClickHouse 可以直接查询 MongoDB 吗？

SELECT trash, garbage FROM mongodb( '127.0.0.1:27017', 'test', 'my_collection', 'user', 'password', 'trash String, garbage String');

24.10 的新内容：
— 连接字符串支持 mongodb:// 协议；
— 下推 WHERE 条件与 ORDER BY；
— 支持所有 MongoDB 数据类型；

SELECT trash, garbage FROM mongodb( 'mongodb://root:clickhouse@localhost:27017/database', 'my_collection', 'trash String, garbage String');

开发者：Kirill Nikiforov。

性能改进

后台合并优化

我们需要优化一个集群的合并，它具有 极高的摄取速度 （每秒 4 亿条记录），机器数量中等（30 台），全部是副本，并在共享存储上并发分配合并任务……

如何做到？

— 首先需要可视化！

后台合并优化

可视化可通过内置 /merges 处理程序访问，
位于 HTTP 接口，类似 /play, /dashboard和 /binary.

开发者：Alexey Milovidov。

Parquet 优化

ClickHouse 24.10 支持使用 布隆过滤器 过滤 Parquet 文件。

注意：大多数工具无法写入布隆过滤器，
即使 Spark 也需要费些功夫才能启用。

开发者：Arthur Passos。

pointInPolygon 利用索引

如果 lat、lon 上有 minmax 索引，
或有 mortonEncode(lat, lon)、hilbertEncode(lat, lon) 索引，地理空间查询会加速。

开发者：Jacky Woo。

各类查询整体改善 10..30%。

一些有趣的功能

通配符授权

此前已支持：

GRANT SELECT ON db.* TO user1; GRANT SELECT ON *.* TO user2;

24.10 的新内容：

GRANT SELECT ON db.table_pefix_* TO user1; GRANT SELECT ON db*.table TO user2;

通配符适用于数据库和表。
可放在末尾，表示数据库或表名的前缀。

撤销权限时可使用与授权时不同的通配符。

开发者：Pufit。

远程文件缓存

如果在 S3 磁盘上有一张 MergeTree 表，
我们此前已提供 本地文件系统缓存.

24.10 的新功能是 缓存直接访问的文件
以及数据湖表，位于 S3 和 Azure.

缓存条目由以下信息标识： 路径 + ETag.

SELECT * FROM s3('s3://datasets/test.tsv') SETTINGS filesystem_cache_name = 'cache_for_s3', enable_filesystem_cache = 1;

开发者：Kseniia Sumarokova。
