# ClickHouse

[ClickHouse](https://github.com/ClickHouse/ClickHouse) 是面向实时分析场景的开源列式数据库。本页从 `22.3` 起收录其 OSS 月度版本，包含官方 Changelog、简体中文翻译、结构化更新总结以及中英文 Release 演示。

## 收录规则

- 版本格式为 `YY.M`，例如 `26.5`。
- 3 月与 8 月版本标记为 LTS。
- Release Card 按版本月份切换春、夏、秋、冬主题色。
- 中文 Release 演示保留原演示的页序、布局、图片、代码和链接，并以网页幻灯片形式在线浏览。
