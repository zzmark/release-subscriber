SELECT now() + INTERVAL 1 MONTH; SELECT now() + INTERVAL '1 MONTH'; SELECT now() + INTERVAL 1 MONTH - INTERVAL 2 DAY; SELECT now() + INTERVAL '1 MONTH -2 DAY'; SELECT now() + (INTERVAL 1 MONTH - INTERVAL 2 DAY); SELECT INTERVAL '1 MONTH -2 DAY'; SELECT (INTERVAL 1 MONTH - INTERVAL 2 DAY); SELECT INTERVAL '1 MONTH 1 MONTH';

数据湖

ClickHouse 可以作为服务器 (clickhouse-server)
或作为工具免安装运行（clickhouse-local）。

ClickHouse 可以存储数据
或即时处理外部存储的数据。

外部数据：
— 远程数据库：MySQL、PostgreSQL、MongoDB、ODBC、JDBC……
— 对象存储：S3、HDFS、Azure、COSN、OSS……
— URL 和本地文件；

各种数据格式：
— 文本：CSV、TSV、JSON、Values、MySQLDump、Regexp……
— 二进制：Parquet、Arrow、ORC、Avro、Protobuf、MsgPack……
— 有固定结构或无固定结构；

数据湖

ClickHouse 现在支持对 Apache Hudi 和 Delta Lake
执行 SELECT 查询。

待办：Apache Iceberg。

优点：
— 这些格式在一定程度上类似 MergeTree
 ，允许增量插入数据，
  逐渐接近 ClickHouse 数据格式；

缺点：
— 来自 Apache/Hadoop/Java 生态的外来数据格式；
— 没有什么是开箱即用的，
  除非你确实知道如何处理；
