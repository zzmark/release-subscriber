APPLY DELETED MASK

批量 DELETE：

ALTER TABLE t DELETE WHERE user = 'Petya'

— 复制除已删除记录之外的全部记录，
  完整重写数据片段。

轻量级 DELETE：

DELETE FROM t WHERE user = 'Petya'

— 通过创建记录掩码进行延迟删除，
  在 SELECT 和合并期间滤除这些记录。

ALTER TABLE t APPLY DELETED MASK

— 在轻量级删除操作之后清理已删除的记录，
  无需执行 OPTIMIZE 查询。

开发者：Anton Popov ⛄。

APPLY DELETED MASK

ALTER TABLE t APPLY DELETED MASK

— 在轻量级删除操作之后清理已删除的记录，
  无需执行 OPTIMIZE 查询。

本质上是将轻量级 DELETE 转换为批量操作。

额外功能：

ALTER TABLE t APPLY DELETED MASK IN PARTITION p

FINAL 优化

FINAL — 在 SELECT 查询期间即时应用合并逻辑。

适用于 Replacing-、Collapsing-、Aggregating-、Summing-
以及其他 MergeTree 表。

可实现 OLTP 数据库中的唯一主键行为，以及 UPSERT、REPLACE、INSERT IGNORE。

可以在查询中显式指定：
SELECT ... FROM table FINAL
或者通过设置： SET final = 1

缺点：SELECT 会变得 更慢.

FINAL 优化

如果表的分区键由主键中的列组成，
则不跨分区合并数据。

开发者：Maksim Kita 🎈。

FINAL 优化

找出主键范围互不相交的数据片段，
避免合并这些数据片段中的数据。

开发者：Maksim Kita 🎈。
