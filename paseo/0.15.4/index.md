## 概览

Paseo 0.15.4 新增 Claude Fable 5.2 和 Mythos 5.2。使用这两款模型需要 Claude Code 2.1.321 或更高版本。

## New Feature

- 两款模型的默认推理强度均为中等。Paseo 仅在 Claude Code 表明可以访问 Mythos 5.2 时显示该模型。（[#9233](https://github.com/getpaseo/paseo/pull/9233)）
