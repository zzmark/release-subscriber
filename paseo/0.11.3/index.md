## 概览

Paseo 0.11.3 在 ACP 提供方目录中新增可选的 Hoplite，并加入目录搜索。添加提供方失败时改用 Toast 通知，同时修复插件提供方误显示“移除”操作的问题。Hoplite 通过企业赞助计划成为 Paseo 的首位赞助商。

## New Feature

- 在 ACP 提供方目录中新增 Hoplite，用户可自行选择启用。
- “添加提供方”目录支持搜索；添加失败时显示 Toast 通知。

## Bugfix / Security

- 修复 Antigravity、Muse Code 等插件提供方误显示“移除”操作的问题。
