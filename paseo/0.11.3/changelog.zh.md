## 0.11.3 - 2026-10-15

[Hoplite](https://hoplite.sh) 通过企业赞助计划成为 Paseo 的首位赞助商。Hoplite 构建云端编码代理，将来自 GitHub、Linear、Slack 等平台的任务转化为拉取请求。感谢 Hoplite 团队对 Paseo 的支持。

### 新增

- 在 ACP 提供方目录中添加 Hoplite，供用户自行选择启用（[#6953](https://github.com/getpaseo/paseo/pull/6953)，由 @odinglyn0 贡献）
- 为“添加提供方”目录添加搜索功能（[#6953](https://github.com/getpaseo/paseo/pull/6953)、[#7030](https://github.com/getpaseo/paseo/pull/7030)）

### 变更

- 将添加提供方失败的提示改为 Toast 通知（[#7030](https://github.com/getpaseo/paseo/pull/7030)）

### 修复

- 修复 Antigravity 和 Muse Code 等插件提供方也显示“移除”操作的问题（[#6568](https://github.com/getpaseo/paseo/pull/6568)，由 @Ctrl-Creeper 贡献）
