## 0.11.0 - 2026-10-07

Paseo 0.11 新增对[插件注册表](https://paseo.sh/plugins)的支持。你可以在那里浏览社区插件，使用 `paseo plugin add owner/slug` 安装插件，或[提交自己的插件](https://paseo.sh/docs/plugins/publishing#plugin-registry)。

**升级前请注意：** `paseo plugin add owner/repo` 现在会从注册表安装，因此直接从 GitHub 安装时请使用 `github:owner/repo`，本地目录则使用 `./path`。
