## 概览

Paseo 0.14.0 允许插件为指定代理提供工具，并在会话打开时添加 MCP 服务器；新增对话折叠、本地语音模型下载和多项消息输入选项。该版本减少大型历史记录、差异和后台处理造成的卡顿。升级后语音模式默认关闭，并需留意语音配置迁移及降级要求。

## Breaking Change

- 语音模式改为默认关闭，需在“语音”设置中主动启用。
- 如果通过环境变量选择 OpenAI 语音服务，需将仅保存在旧版 `providers.openai` 中的密钥和端点移至“语音”设置。
- 降级到 0.13.2 前，需恢复备份的 `config.json`，或转换由 0.14.0 保存的语音凭据和空闲清理设置。

## New Feature

- 插件可向指定代理提供工具，并在每次会话打开时添加 MCP 服务器。
- 聊天显示设置支持工具调用分组和已完成轮次折叠；折叠后的轮次可展开阅读完整对话。
- “语音”设置支持配置服务提供商，并一键下载包括 SenseVoice、Whisper 在内的本地模型，用于中文听写。
- 可选择 Enter 或 ⌘/Ctrl+Enter 发送消息；网页端和桌面端空输入框支持用上、下方向键调出已发送消息，长按发送按钮可选择排队或立即发送。
- 支持按项目选择编辑器（包括 macOS 上的 Xcode）；子代理面板增加返回父代理的链接，提问卡片支持可点击链接和可选择说明文字。

## Performance

- 符合条件的代理运行时空闲一小时后释放，下次提示时恢复已保存会话；隐藏聊天不再渲染收到的文本更新。
- 改善网页端大型导入会话列表的响应速度，减少大型差异高亮与换行，以及大型 Claude、OMP 历史记录打开和分页时的卡顿。
- 减少插件构建、图片处理、配置重载期间的守护进程卡顿，以及刷新工作区和项目时的阻塞式文件系统操作。

## Bugfix / Security

- 修复 WebGL 纹理图集变化造成的终端字形损坏、大量 ACP 终端输出阻塞请求、SSH 隧道失败引发未处理 EPIPE，以及 Windows 短暂文件锁阻止原子保存的问题。
- 修复恢复工作区时加载不结束、代理标签页出现在无关工作区、后台 Git fetch 弹出凭据提示，以及 Pi 手动压缩上下文期间消息未等待便失败的问题。
- 修复重叠轮次的工具更新产生重复行、ACP 推理混入助手回复，以及 OpenCode v2 子代理缺少模型和 token 详情的问题。
- 修复 Markdown URL 端口与路径解析、行内代码尺寸、文件链接预览和工具提示，以及手机消息输入框与命令建议重叠等问题。
- 修复停靠窗口宽度为 600–719 时的导航和设置布局、切换设置章节时主机与滚动位置丢失，以及模型选择器和错误提示布局问题。
