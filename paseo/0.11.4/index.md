## 概览

Paseo 0.11.4 修复了关联 Hoplite 项目的工作区中的模型发现问题：Hoplite 不再在“设置 → 提供方”中显示错误，而是正常发现模型。发布说明同时保留了对首位企业赞助商 Hoplite 的致谢。

## Bugfix / Security

- 修复关联到 Hoplite 项目的工作区中，Hoplite 在“设置 → 提供方”中显示错误而非发现模型的问题。
