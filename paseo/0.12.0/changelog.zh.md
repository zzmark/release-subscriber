## 0.12.0 - 2026-10-19

后台工作区、支持手机上跨段落选择文本的新 Markdown 渲染器、重新设计的手机布局，以及 120 多项修复。

**升级前请注意：** `paseo run --background` 已弃用，改用 `--no-wait`；如果守护进程未在 15 秒内确认，`paseo permit allow` 和 `deny` 现在会以非零退出码退出

### 新增

- 新增后台工作区；除非开启“显示后台工作区”，否则不在侧栏中显示 ([#5039](https://github.com/getpaseo/paseo/pull/5039), [#7141](https://github.com/getpaseo/paseo/pull/7141)，贡献者：@gpambrozio, @marvin-ambrozio)
