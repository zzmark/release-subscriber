## 概览

Paseo 0.15.0 让终端程序能够跨守护进程重启、崩溃及受支持的更新继续运行，并提供默认关闭的代理恢复选项，使中断的代理在原有对话中继续工作。移动端终端改用原生渲染，新增文本选择手柄，重新连接时可恢复最多 10,000 行终端历史。

首次从 0.14.0 升级仍会关闭终端；终端保留功能在新守护进程安装后生效，Windows 桌面应用升级也仍会关闭终端。代理恢复需在主机设置 → 代理中启用 **重启后恢复代理（Resume agents after restart）**，恢复时发送 `Resume working.` 或自定义提示词。

## Breaking Change

- 降级至 0.14.0 前，必须恢复备份的 `config.json`，或移除已保存的代理恢复和用量检查设置。

## New Feature

- 新增终端进程保留与可选的代理重启恢复；可复用正在运行的 OpenCode v2 服务，并将回复中已识别的代理命令插入消息编辑器草稿。
- iOS 与 Android 终端新增可拖动的文本选择手柄；手机和平板可跟随系统方向设置旋转。
- 通过 `.worktreeinclude` 选择要复制到新工作树的忽略文件，在初始化设置和代理启动前完成复制。插件可用 `worktree.create.before` 指定工作树位置和创建选项；新增 `server.addHook`，并在工作区初始化设置和代理启动前等待 `worktree.create.after` 执行完毕。
- 守护进程统一支持 `HTTP_PROXY`、`HTTPS_PROXY` 和 `NO_PROXY`。用量仅在显示时获取，可通过主机设置完全禁用检查，并显示精确重置时间和更精确的倒计时。

## Performance

- 重新打开已缓存的聊天时，不再重新读取和保留未使用的 Codex 历史副本；插件流式快照用完即释放，减少长期保留的数据。
- 插件通过缩小客户端包及跨重新连接、应用启动复用缓存，减少下载量；主机暂时断开时保留插件界面和本地状态。
- 大型守护进程响应拆分为多个中继帧，避免达到单帧上限后断开连接；向应用发送前截断过大的聊天条目，包括大型工具结果和嵌入数据。

## Bugfix / Security

- 修复 Claude 对话回退、重新打开后恢复子代理时的重复行和回复缺失，以及 Claude 设置文件被 Paseo 启动设置覆盖丢弃的问题。修复引导消息在对话轮次启动期间替换原始提示词的问题。
- 修复无提示词创建的 Codex 代理在运行时重新打开后失败、保留名称的自定义 Codex 服务提供商异常，以及 ACP 启动错误延迟报告和分批命令导致技能缺失的问题。
- 修复 Pi 工具结果图片缺失、已完成的 Pi 与 Claude 子代理状态错误、复用插件子代理显示旧状态、新代理立即显示为已完成，以及回退插件对话后已丢弃消息重现的问题。
- 修复 Android 后台折叠、展开及旋转后的布局尺寸，移动端聊天状态被页眉遮挡，以及终端中日韩字符、emoji、样式文本和光标列对齐问题。终端重新连接时恢复配置的回滚历史，最多 10,000 行。
- 修复侧栏订阅释放后的标题与状态更新、折叠分组中当前工作区不可见、相对聊天链接指向错误文件、跨窗口删除代理后标签页无法关闭，以及窗口隐藏期间切换主题后文本颜色未更新的问题。
- 修复直接连接 Host 字段对 host:port 和粘贴 URL 的支持、非 Mac 键盘通过普通 HTTP 访问时的终端 Ctrl+V 粘贴、网页菜单尺寸回跳和分栏分隔线拖动偏移。
- 修复历史加载失败后反复打开服务提供商运行时的问题，并提供重试；修复 MiniMax Code 目录命令选择可执行文件、Git 更新因原生文件系统监视器启动延迟而未被观察到，以及向 Codex 和 Pi 传递内置技能参数错误的问题。
