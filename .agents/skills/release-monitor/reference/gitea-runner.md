# Gitea Runner release blogs

Read .release-monitor/software/gitea-runner.yaml and [gitea-blogs.md](gitea-blogs.md) for the shared official blog workflow. When publishing Runner releases, also read github-gitea.md and report-format.md.

- Runner release metadata and original bodies come from gitea.com/gitea/runner, using the Gitea API or tea as described in github-gitea.md.
- Use source.release_blog_index_url for Runner announcements; exclude Gitea server articles. Match the exact Runner version and Gitea Release link.
- Translate the entire verified article, including historical Changelog sections. Match independent announcements by their title and opening text, not merely by historical version headings.
- Follow the shared attribution, local blog links, existing-version supplementation and verification steps in gitea-blogs.md.
