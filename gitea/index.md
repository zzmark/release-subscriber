# Gitea

[Gitea](https://github.com/go-gitea/gitea) 是提供 Git 仓库托管、代码评审、工单、软件包和 Actions 的自托管开发平台。本页收录从 **1.26.0** 起的正式版本，提供原始 Changelog、完整简体中文翻译、结构化更新总结及官方发布博客译文。

自 **28.0.0** 起，上游移除历史版本号的 `1.` 前缀；目录保留官方实际版本，不将 `1.26.0` 改写成 `26.0.0`。详见[官方版本说明](https://blog.gitea.com/release-of-28.0.0/)。
